Build One Thing

Open aistudio.google.com, sign in with a personal Gmail (school accounts can have it turned off), and click Build in the left sidebar. Copy a prompt below, fill in the brackets, and paste it in.

Recipe template

Start here

Who: [who uses this app]
What: Build a [type of app]. It [feature 1], [feature 2], and [feature 3].
Why: I want to [problem it solves].
How: [one page? buttons? what happens step by step?]
Looks: [colors, style, vibe]

Rounds

  1. Build, 5 min. Pick an idea, write the recipe, generate it.
  2. Fix, 7 min. Test every button. Make one change through chat and one through Annotation Mode.
  3. Stretch, 6 min. Add one AI Chip, or a feature you thought of while testing.

One person types, the other tests. Switch halfway.

Idea prompts

School

Schedule Snapshot

Who: I'm a community college student juggling classes, work, and clubs.
What: Build a visual weekly schedule planner. I add each class with its name, days, start and end time, and room, and it shows a color-coded Monday–Friday calendar grid from 7am to 10pm. Highlight any time conflicts in red, and show my total class hours per week. Bonus: a box where I can paste my schedule as plain text and Gemini fills in the classes for me.
Why: I want to see my whole week at a glance and catch conflicts before I register.
How: One page. Clicking a class block lets me edit or delete it.
Looks: Clean and minimal, soft pastel color for each class, rounded blocks.
School

3D Surface Explorer

Who: I'm a Calculus 3 student learning multivariable functions.
What: Build a 3D graphing tool. I type a function z = f(x, y), like sin(x)*cos(y) or x^2 - y^2, and it draws the surface in 3D with labeled x, y, and z axes. I can rotate and zoom with my mouse. Add preset buttons for a paraboloid, a saddle, and a ripple, plus sliders to change the x and y range.
Why: I want to see what these surfaces actually look like instead of imagining them from the equation.
How: One page. Input box and presets on the left, graph on the right. Show an error message if the function can't be read.
Looks: Dark background so the surface colors pop, with a smooth color gradient based on height.
Club

Club landing page

Who: I'm an officer of [club name] at [college], and new students are the audience.
What: Build a one-page landing page for the club with these sections: a hero with the club name, tagline, and a "Join us" button; About (what we do and who it's for); Meeting info (day, time, room); Upcoming events as 3 cards; Officers with a photo placeholder, name, and role; a short FAQ; and a footer with Instagram and Discord links.
Why: I want one link we can share on Instagram that tells people everything they need to show up.
How: Smooth scrolling, a sticky top nav that jumps to each section, and it should look good on a phone.
Looks: [club colors], [vibe: playful, techy, minimal], with a friendly serif or rounded font.
Personal

Mood playlist picker

Build a mood-based playlist picker. I choose a mood (focused, hype, chill, sad), and it uses Gemini to suggest 8 songs with the artist and a one-line reason for each. Moody dark theme with neon accents.
Fun

Would You Rather

Build a "Would You Rather" game for college students. It uses Gemini to generate a new question each time I click a button, and I pick an option to see a fun fake percentage of how others voted. Colorful, game-show style.

5 rules

  1. One change per message. If five changes break it, you won't know which one did.
  2. Describe bugs like you'd tell a tutor: what you did, what you expected, what happened instead. Not "it's broken," but "When I click Next on the last card, the page goes blank. I expected it to loop back to card 1."
  3. Click every button. The AI can say a feature works when it doesn't. You're the tester.
  4. If the chat spirals, start fresh. Open a new build and paste a clean summary of what you want.
  5. No real secrets. No passwords, API keys, or personal info in an app you might share.

If you get stuck

Can't open AI StudioSwitch to a personal Gmail account.
App is blank or shows an errorTell the chat exactly what you see, or regenerate.
Hit the daily limitPair up and share one account. Limits reset at midnight Pacific.
App looks genericAdd a Looks section with specific colors and style.
A change broke somethingRestore the previous version, then ask for one smaller change.
3D graph won't showAsk the chat to "use Plotly.js for the 3D surface."
