Idea prompts

School

3D Surface Explorer

Who: I'm a Calculus 3 student learning multivariable functions.
What: Build a 3D graphing tool. I type a function z = f(x, y), like sin(x)*cos(y) or x^2 - y^2, and it draws the surface in 3D with labeled x, y, and z axes. I can rotate and zoom with my mouse. Add preset buttons for a paraboloid, a saddle, and a ripple, plus sliders to change the x and y range.
Why: I want to see what these surfaces actually look like instead of imagining them from the equation.
How: One page. Input box and presets on the left, graph on the right. Show an error message if the function can't be read.
Looks: Dark background so the surface colors pop, with a smooth color gradient based on height.

5 rules

  1. One change per message. If five changes break it, you won't know which one did.
  2. Describe bugs like you'd tell a tutor: what you did, what you expected, what happened instead. Not "it's broken," but "When I click Next on the last card, the page goes blank. I expected it to loop back to card 1."
  3. Click every button. The AI can say a feature works when it doesn't. You're the tester.
  4. If the chat spirals, start fresh. Open a new build and paste a clean summary of what you want.
  5. No real secrets. No passwords, API keys, or personal info in an app you might share.
Rule 4

Hand off to a fresh build

Try restoring the previous version first. If the chat itself has gone bad, paste this into it, then paste the result into a new build. Read it before you paste, because the AI can describe its own app wrong.

Write a handoff so I can start a new build. Use Who, What, Why, How, and Looks to describe the app as it works right now. Then list what's broken, in one or two lines each. Don't include things we tried that didn't work.

If you get stuck

Can't open AI StudioSwitch to a personal Gmail account.
App is blank or shows an errorTell the chat exactly what you see, or regenerate.
Hit the daily limitPair up and share one account. Limits reset at midnight Pacific.
App looks genericAdd a Looks section with specific colors and style.
A change broke somethingRestore the previous version, then ask for one smaller change.
3D graph won't showAsk the chat to "use Plotly.js for the 3D surface." (Plotly.js is a free chart library that draws 3D graphs you can rotate and zoom.)
