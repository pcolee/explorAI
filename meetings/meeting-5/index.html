Recipe prompt

Same app, with the recipe.

Who: I’m a community college student juggling classes, work, and clubs.

What: Build a visual weekly schedule planner. I add each class with its name, days, start and end time, and room, and it shows a color-coded Monday–Friday grid from 7am to 10pm. Highlight time conflicts in red, and show my total class hours per week.

Why: I want to see my whole week at a glance and catch conflicts before I register.

How: One page. Clicking a class block lets me edit or delete it.

Looks: Clean and minimal, a soft pastel color for each class, rounded blocks.

Two ways to change it

Chat is for features. Annotation Mode is for “this thing right here.”

Chat

Ask for one new feature.

Add a dark mode toggle.

Annotation Mode

Highlight the thing on the screen, then describe the change.

Make this button bigger and pastel pink.

You don’t need to know what the code calls it.

Tips and tricks

5 rules for vibe coding

1

One change per message. If five changes break it, you won’t know which one did.

2

Describe bugs like you’d tell a tutor: what you did, what you expected, what happened.

3

Click every button. The AI can say it works when it doesn’t. You’re the tester.

4

If the chat spirals, start fresh. Paste a clean summary into a new build.

5

No real secrets. No passwords, API keys, or personal info in an app you might share.
