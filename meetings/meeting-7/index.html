Part 1

What MCP is

One standard way for AI to reach your apps.

MCP · Model Context Protocol

One standard way for AI to connect to apps and tools.

Model

The AI itself, like Claude.

Context

What it can read right now: Meeting 3’s context window.

Protocol

Rules both sides agree on, so they can talk to each other.

Example📅 Google Calendar: Claude asks for this week’s events, the calendar sends them back, and Claude reads them.

MCP is like USB for AI.

Before: 9 different connections, one for every pair.

With MCP: one plug on each side.

Any AI that supports MCP can use any app that supports it.

Hands-on · 20 minutes

Connect one app. Then try as many as you can.

20:00

Level 1

  • Find a doc in your Drive and summarize it.
  • Ask Claude what your busiest day this week is.

Level 2

  • Combine two apps: “Based on my calendar, when can I study for my exam this week?”
  • Ask Claude to find every doc you edited this month and group them by topic.

Level 3 · Bonus

  • Install Claude Desktop and connect the filesystem server.
  • Ask it to summarize the notes in a folder, or sort a folder’s files by type.

No account, or rather not use yours? Pair up with a neighbor.

Part 3

Ask first

What should an agent never do without asking?

Discussion · 7 minutes

Let’s talk about what you just connected.

1Which app would you connect next, and what would you use it for?

2What should an agent never be allowed to do without asking first?

3Would you let an agent send emails for you? Why or why not?

4What could go wrong if an agent had access to all your apps?

7:00

Which actions need your OK first?

Fine to just do

  • Search your files
  • Read a doc
  • List your events
  • Summarize what it found

Ask first

  • Send an email
  • Delete a file
  • Pay for something
  • Post for you

More access means more useful, but also more risk. Good agents ask before taking actions that can’t be undone.

One thing to remember

MCP is one standard plug that lets AI use your apps.
